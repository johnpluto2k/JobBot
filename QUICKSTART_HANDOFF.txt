HOW TO RUN NORMALLY
================================================================================

Terminal 1 (Backend):
  $ python -m job_bot.api
  Listens on http://127.0.0.1:8000

Terminal 2 (Frontend):
  $ cd web && npm run dev
  Listens on http://localhost:5173

Browser:
  http://localhost:5173 → Click "Companies" tab

Log a job:
  $ python -m job_bot.intake "<url>" "<company>" "<title>" --portal linkedin
  Portals: indeed, linkedin, jobright, glassdoor, ziprecruiter, workday, etc.
  Statuses: applied, saved, rejected, offer
