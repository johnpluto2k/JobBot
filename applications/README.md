# Your applications

The coach makes one folder here for each job you apply to:

```
applications/
  Northwind_Data-Analyst/
      Rivera_Sam_Northwind_DataAnalyst_Resume.pdf        <- upload this
      Rivera_Sam_Northwind_DataAnalyst_CoverLetter.pdf   <- and this, if asked
      posting.md                                         the job posting, saved the day it was fetched
      source/                                            the LaTeX files behind the PDFs
  _dropped/                                              ones you decided not to send
```

To start one, tell the coach: "Tailor an application for this posting:" and
paste the link.

Whether you applied, and what happened next, is recorded in your tracker
sheet, not here.

Nothing in this folder is ever uploaded with the project.
