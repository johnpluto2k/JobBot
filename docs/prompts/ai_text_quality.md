# Prompt: Make Job Bot's AI-generated text sound less like AI wrote it

Paste this into Claude Code from the `Job Bot` repo root.

## Context — where the AI text actually comes from

Quick correction on framing before the fix: this isn't something a "skill" can patch. Skills (like the `career-coach` skill built earlier) only shape how *I* respond in a Claude chat. The resume bullets, cover letters, and LinkedIn "About" section are generated by direct Anthropic API calls buried inside this codebase's own Python — completely separate from any skill:

- `job_bot/tailor.py` → `_llm_rewrite()` — rewrites resume bullets to mirror the JD.
- `job_bot/cover_letter.py` → `_llm_cover_letter()` — drafts the cover letter.
- `job_bot/linkedin_optimizer.py` → `_llm_about()` — drafts the LinkedIn About section.

None of these three prompts currently give the model any style guardrails beyond "don't fabricate facts" — so it defaults to generic LLM writing habits: corporate clichés (leverage, spearhead, utilize, robust, dynamic, results-driven, passionate, seamless, synergy), stock transitions (furthermore, moreover, in today's fast-paced landscape), uniform sentence rhythm, and every bullet starting the same way. That's the "sounds like AI wrote it" problem — fixable by adding explicit anti-cliché instructions to each prompt, not by installing anything.

The fourth surface — `career-coach` skill chat responses — genuinely is skill-governed; its fix belongs in the skill file (see part 2 below).

## Part 1: Add shared style guardrails to the three generation prompts

Add a new small module, `job_bot/writing_style.py`, with a reusable style-rules string all three prompts import (avoids repeating/drifting the same rules three times):

```python
"""Shared anti-cliché writing guardrails for every LLM-generated text surface
(resume bullets, cover letters, LinkedIn About). Import STYLE_RULES and splice
it into any prompt that asks Claude to write candidate-facing text."""

BANNED_PHRASES = [
    "leverage", "leveraging", "spearhead", "spearheaded", "utilize", "utilized",
    "robust", "dynamic", "results-driven", "detail-oriented", "team player",
    "passionate about", "seamless", "seamlessly", "synergy", "synergies",
    "furthermore", "moreover", "in today's fast-paced", "ever-evolving",
    "cutting-edge", "game-changer", "delve into", "unlock", "unlocking",
    "empower", "empowering", "holistic", "streamline", "streamlined",
]

STYLE_RULES = f"""
Writing style rules — this text will be read by a human, not graded on buzzword density:
- Never use these words/phrases: {", ".join(BANNED_PHRASES)}.
- Vary sentence length and structure — don't start consecutive lines/bullets with
  the same verb or pattern.
- Every claim should carry one concrete, specific detail (a number, a tool name,
  a scope) rather than a generic quality claim like "strong communication skills."
- Write the way a sharp, slightly understated person would describe their own
  work to a peer — not the way a corporate brochure would describe it.
- No throat-clearing openers ("I am excited to..."), no generic closers
  ("I look forward to hearing from you") unless they carry a specific reason why.
"""
```

Then in each of the three functions, splice `writing_style.STYLE_RULES` into the existing prompt string (append it, don't replace the factual/no-fabrication instructions already there — those stay):

- `tailor.py::_llm_rewrite()` — the prompt currently only says "strong action verb first, no pronouns"; add the style rules so rewritten bullets don't all converge on the same three verbs.
- `cover_letter.py::_llm_cover_letter()` — already bans "I am writing to express"; extend that instinct with the full shared list instead of a single hardcoded example.
- `linkedin_optimizer.py::_llm_about()` — currently has zero style guidance beyond word count and tone adjectives ("confident but not boastful"); add the shared rules so it stops reading like every other LinkedIn About section.

## Part 2: Apply the same standard to the `career-coach` skill

The `career-coach` skill (`SKILL.md`, already installed) generates conversational coaching text, not API-called text, so its fix is a SKILL.md edit rather than a Python change — but the underlying problem is the same. Add a short style section to the skill instructing it to:
- Avoid generic coach-speak ("you've got this!", "keep pushing forward!", "it's a marathon, not a sprint") in favor of specific, grounded observations tied to the actual pipeline numbers it just pulled.
- Vary phrasing between check-ins rather than reusing the same sentence templates every time ("Lead with X, then Y, then Z") — the structure in Step 3 of the skill is a guide to *content order*, not a sentence template to fill in verbatim.

- Regenerate a LinkedIn audit (`python -m job_bot.linkedin_optimizer`) before/after and do the same comparison on the About section.
