# Put everything here

Drop in everything you already have about yourself. Don't tidy it first.

- every version of your resume
- cover letters you have written
- transcripts
- project write-ups, reports, presentations
- award letters, performance reviews, recommendation letters
- your LinkedIn profile saved as a PDF, and your LinkedIn connections export

PDF, Word, text and spreadsheet files all work. Subfolders are fine.

Then tell the coach "my documents are in". It reads all of it and writes your
profile.

Nothing in this folder is ever uploaded with the project.
