% WHAT THIS FILE IS
%   This is everything you have ever done: every job, project, club, award
%   and skill, with every bullet worth keeping. It runs as many pages as it
%   needs and is never sent to an employer. Tailored one-page resumes
%   (resume.tex) are CUT from it: pick the entries and bullets that fit one
%   job posting, copy them over, trim to a page.
%
%   Nothing goes in here that is not true. If a number is an estimate, make
%   it one you could defend in an interview. A tailored resume may only use
%   what is in this file, so a claim that is wrong here is wrong everywhere.
%
% HOW TO USE
%   1. Sam Rivera is a made-up person. Replace every entry with your own.
%   2. Compile: paste into Overleaf, or run `pdflatex master_resume.tex`.
%   3. Check:   python tools/check_resume.py master_resume.pdf --master
%   4. When you do something new, add it here first, then re-tailor.
%
% WRITING BULLETS
%   - Start with an action verb, and avoid starting two bullets with the same
%     one; every repeat is a bullet you cannot use next to its twin later.
%   - Write each bullet as ONE line that ends 92-99% of the way to the right
%     margin, so it can be dropped into a tailored resume unchanged.
%   - Main entries carry 5-7 bullets here; a tailored resume keeps 3 per job,
%     3 per project and 2 per leadership entry.
%   - Plain ASCII: write "resume" and "cafe" without accents, and use " -- "
%     (a spaced en dash) in headings.
%------------------------
